# Zotero Book Splitter

一款帮助读者整理长篇 PDF 的 Zotero 9 插件，适合论文集、选集和篇幅较长的著作。

它可以读取 PDF 原生目录书签、通过你配置的 AI 接口识别目录，或在本地扫描目录页，列出章节标题、作者和页码供你核对。确认后，可将选中的章节生成：

- 可单独引用的 Zotero 文献条目和章节 PDF；
- 原书条目下的独立章节 PDF；
- PDF 原生目录书签（适用于缺少书签的文件）。

原书记录、笔记和完整 PDF 会保留，不会被覆盖。你可以只处理需要的章节；重复执行时，即使检测到同名章节，也会按你的操作再次创建副本。

## 安装

1. 下载 [`zoterobooksplitter0.13.6.xpi`](https://github.com/airalinknowledge/zotero-book-splitter/raw/main/zoterobooksplitter0.13.6.xpi)。
2. 打开 Zotero，进入“设置 → 高级 → 扩展”。
3. 点击齿轮按钮，选择“从文件安装附加组件”，然后选择下载的 XPI。
4. 按提示重启 Zotero。

适用版本：Zotero 9。

## 使用提示

- 自动识别结果会受 PDF 排版、扫描质量和目录格式影响，生成前请检查章节名称、作者和页码。
- AI 识别需要你自行配置兼容的 API。PDF 内容是否发送给第三方服务，取决于你选择的识别方式和服务商；介意隐私时可使用本地扫描或原生书签识别。
- 本插件目前处于小范围内测阶段。建议先在少量文献上试用，并保留原文件备份。
